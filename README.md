# Maltix

Maltix is a free, no-login malware sandbox website concept inspired by security analysis platforms like VirusTotal. It lets a user upload:

- a file
- a website URL
- an app package

The UI then simulates an AI-powered sandbox review and explains:

- whether malware is suspected
- the likely malware type
- what the malware can do to a PC, laptop, phone, tablet, or other device
- how dangerous the threat appears

## Features

- Free and no-login experience
- Dark cyber-security dashboard look
- File, website, and app scan tabs
- Threat score and risk explanation panels
- Safety-focused language for a public-facing malware analysis demo

## Run locally

Open `index.html` directly in a browser.

## Project files

- `index.html` — landing page and malware sandbox form
- `styles.css` — complete layout and visual design
- `script.js` — tab switching and malware simulation logic

## Note

This is a front-end prototype and demo experience. It simulates malware analysis behavior for educational and UI-design purposes, rather than providing a real security-scanning engine.
