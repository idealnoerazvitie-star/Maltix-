What this demo does

Useful interactions, honest limits

Local file review

Reads the file in-browser only, calculates a SHA-256 hash, and shows basic metadata.

Safe URL checks

Validates http/https format without fetching the destination, running scripts, or exposing your browsing session.

Fictional samples

Lets you explore warning-style examples for files, URLs, and apps without pretending they are real detections.

Export report

Downloads a plain-text report summarizing the sample findings and risk guidance.

Privacy and safety

Your files stay on this page.

No upload

Files are processed locally in the browser only. No bytes are sent to a backend for this demo.

No execution

Maltix does not open or run suspicious files. This is a user-experience prototype, not a real sandbox.

Real security needs backend

Production malware analysis requires sandbox infrastructure, policy controls, and strict storage rules.

Human review

Anything suspicious should be investigated with a trusted security team, endpoint product, or incident-response workflow.
